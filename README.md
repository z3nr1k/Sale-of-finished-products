# Реализация готовой продукции

## Описание
Репозиторий содержит модели, документацию и сценарии для информационной системы учёта реализации готовой продукции.  
Предметная область: оптово-розничная торговля товарами (наименование, цены, справочная информация), учёт покупателей, сделок и документов.

## Структура
- `Общее_Описание.txt` – краткое описание предметной области и задач системы.
- Ветка `extra` – дополнительные материалы:
  - `Методы_распределения.txt` – способы распределения товаров, заказов и ресурсов.
  - `Рекомендации_по_распределению.txt` – практические советы по оптимизации распределения в рамках реализации готовой продукции.

## Основные сущности
- **Товар** (наименование, оптовая/розничная цена, справочная информация)
- **Покупатель** (наименование, адрес, телефон, контактное лицо)
- **Сделка** (дата, количество, цена продажи, ссылки на товар и покупателя)
- **Документ** (накладная, счёт-фактура, статус)

## Ключевые сценарии
1. Оформление продажи (выбор покупателя и товара, расчёт суммы, создание документа)
2. Регистрация нового покупателя
3. Формирование отчёта по продажам за период

## Технологии
- PlantUML (диаграммы)
- SQL (схема базы данных)
- Git (ветвление)
